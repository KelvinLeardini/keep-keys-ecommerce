Sobre o Projeto

O Keep Keys foi desenvolvido como um projeto acadêmico para o curso de Análise e Desenvolvimento de Sistemas (ADS). Nosso objetivo é aplicar conceitos práticos de front-end, lógica de programação e design de interfaces na construção de uma plataforma gamer funcional e moderna.
